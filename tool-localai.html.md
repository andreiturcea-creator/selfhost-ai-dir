## How do you self-host it?

See the official README for Docker or binary install. A 2 vCPU / 4 GB VPS runs most UIs; LLM runtimes need a GPU or must run small quantised models on CPU.

## What are the alternatives?

Ollama, vLLM, llama.cpp
